# 自动点赞脚本 (Z键连发)

这是一个用于浏览器的 Userscript，自动模拟按下 `Z` 键以实现“连发点赞”效果。脚本在页面右下角显示状态指示器，并支持快捷键控制。

**主要功能**
- **自动连发 Z 键**：默认每 200ms 触发一次，模拟真实手速。
- **快捷键控制**：`Ctrl + Shift + Z` 切换 开启/暂停；`Ctrl + Shift + X` 彻底停止。
- **状态指示器**：页面右下角显示当前状态（待命 / 运行中 / 已暂停）。

**安装**
1. 安装 Tampermonkey 或 Greasemonkey 浏览器扩展（Chrome/Edge/Firefox 均支持）。
2. 新建一个 Userscript，并将仓库中的 `indx.js` 全部内容复制粘贴进去。
3. 保存并在目标网站打开页面后按 `Ctrl + Shift + Z` 开始连发。

**使用说明**
- 启动/暂停：按 `Ctrl + Shift + Z`。
- 停止并清理：按 `Ctrl + Shift + X`。
- 指示器位于页面右下角，颜色与文本会随状态变化。

**自定义**
- 修改连发速度：打开 `indx.js`，找到 `setInterval(..., 200)`，将 `200` 改为所需的毫秒数（例如 `500` 表示 0.5 秒）。
- 触发目标元素：脚本使用 `document.activeElement || document.body` 作为事件目标；如需指定目标，请在脚本中修改 `target` 的获取逻辑。

**兼容性**
- 现代浏览器（支持 Userscript 的扩展）均可运行。脚本基于标准 DOM KeyboardEvent，理论上跨平台兼容。

**注意与警告**
- 请勿在明确禁止自动化或可能触发封禁的平台上使用此脚本，自动操作可能导致账号被限制或封禁。
- 本脚本用于学习与自动化测试场景，使用者需自行承担风险和法律责任。
